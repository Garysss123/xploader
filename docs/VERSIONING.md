# Public versions

The first public xploader release is **v1.0**. Further public versions are
planned within the **v1.0 to v1.13** series. This is the project's chosen
versioning convention, not a promise of a particular feature or release date.

Download names and release titles use the public version. Native build and
recovery guard numbers remain in source manifests and validation records so
that an installed image can be traced to its exact source and tests.
